# MODFLOW-USG-AMG v1.0.0

Windows x64 release of USGS MODFLOW-USG 1.5 with the verified MPI-178 HYPRE integration. Rank 0 runs the groundwater model. MPI ranks cooperate in the GMRES + BoomerAMG linear solve. The IJ matrix and both IJ vectors are reused when the sparsity pattern is unchanged. GMRES and BoomerAMG are created for each solver call.

## Install

1. Download `MODFLOW-USG-AMG-Windows-x64.zip`.
2. Check its SHA-256: `4c6f648ed55dd00875120b55d3531701a1fc56986f637a35a47ba9a21faab5b4`.
3. Unzip it. Leave `mfusg_amg_mpi.exe`, `libquadmath-0.dll`, `libgcc_s_seh-1.dll`, and `libwinpthread-1.dll` in the same folder.
4. Run `redist\msmpisetup.exe` once per machine. This is Microsoft MPI runtime v10.1.3 (file version 10.1.12498.52). The SDK is not required. The same installer is available from https://www.microsoft.com/en-us/download/details.aspx?id=105289.
5. From the model directory run `mfusg_amg_mpi.exe model.nam`.

The executable inside the ZIP is the verified binary, SHA-256 `da67fe6e96f3550bbed17d7256edbdcd076443c8acbba94f63586b78ec1b3036`. It was not rebuilt for this release.

## SMS

Set `LINMETH` to 3 and add a line `AMG <processes> <gmres_rtol>`. The process count is 1 to 256. The GMRES relative tolerance is `1e-15` to `1e-2`. `HICLOSE` is not the GMRES tolerance. If the process count is greater than 1, the program starts `mpiexec` itself.

## Changelog

- First public release.
- Solver implementation: MPI-178. HYPRE 2.33.0 is linked statically.
- Windows package includes the three GCC/MinGW runtime DLLs and Microsoft's unmodified MS-MPI runtime installer.

## Tests

USGS model 01A matched the MPI-178 reference byte for byte on the development machine (`flow.hds`, `flow.cbc`, exit code 0, 2 processes). The same ZIP passed the 01A regression test on a Lenovo Yoga 7 computer without MSYS2 or HYPRE.

## Limitations

The prebuilt program is 64-bit Windows only and needs the Microsoft MPI runtime. Source builds were verified with MSYS2 UCRT64 and a static MPI build of HYPRE 2.33.0. MPI does not parallelize the whole MODFLOW run. BoomerAMG parameters are those of the verified binary. A variant that kept GMRES and BoomerAMG objects between solves was tested and was not adopted.

Source code for this release is the tagged source tree. The ZIP is attached to the release and is not stored in Git.
